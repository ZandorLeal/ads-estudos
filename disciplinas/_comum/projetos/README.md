# Projetos cruzados

Projetos que usam mais de uma disciplina ao mesmo tempo, por exemplo uma página feita em FrontEnd,
com interação de Dinâmico e decisões de UX.

Cada projeto tem uma pasta própria com um `README.md` que lista:
- **Disciplinas de origem** (link para a pasta de cada uma)
- O que cada disciplina contribui

E o [`README`](../../../README.md) do repo lista os projetos.
